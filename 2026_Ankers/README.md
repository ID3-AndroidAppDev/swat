# Ankers


#### To run the app, please do the following:
1. Run **main.py** to initialize the web app. This will open your browser.

2. Please refresh the site once entering, because it is a bit janky at startup.


 notes:
* The database **ankers.db** has been used for previous testing. Please do try to use the Hiragana deck, as it is the only complete one.
* You can enable Custom Study Mode in the general settings, which enable manual editing of status and SRS level progression. This will allow you to test the review cycle, if needed.
